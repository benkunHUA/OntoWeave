# P3 变成对象

- 状态：⏳ 未开始
- 目标：把整理好的数据集字段映射成对象属性和关系，生成可查询的对象实例与关系实例。
- 完成标准：能指定对象类型、唯一标识和显示名称；字段能映射到属性；能生成并查询对象实例和关系实例。

## 任务拆分

| 子任务 | 状态 | 说明 |
|---|---|---|
| 3.1 对象映射技术设计 | ⏳ 未开始 | 数据集字段到对象属性、唯一标识、显示名称、关系映射 |
| 3.2 映射配置与校验 | ⏳ 未开始 | 类型兼容、必填字段、唯一性、冲突处理 |
| 3.3 对象实例生成 | ⏳ 未开始 | 从已发布数据集版本生成对象实例 |
| 3.4 关系实例生成 | ⏳ 未开始 | 依据外键或映射规则生成关系实例 |
| 3.5 查询与增量更新 | ⏳ 未开始 | 对象/关系查询；新版本生成后的更新语义 |

## 已确认约束

- 只消费已发布的数据集版本，不直接读取同步运行中的临时数据。
- 对象和关系进入现有本体共享池，复用已有对象类型、属性和关系定义。
- 生成过程必须有运行记录，失败不破坏已有实例。

## 待讨论议题

1. 字段与属性的类型映射和校验规则。
2. 唯一标识、显示名称和重复数据的处理。
3. 关系实例的依据：外键、映射表还是显式规则。
4. 数据集新版本生成后，对象实例是全量替换还是增量合并。
5. 对象实例的存储位置与查询接口。
6. 映射失败、字段缺失和类型不兼容如何展示给用户。
