# P2 数据整理

- 状态：🟡 技术设计中（议题 1/7 已确定）
- 目标：把同步进来的数据集通过可视化流程整理成新的派生数据集版本，并能手动构建、定时运行和追踪来源。
- 完成标准：能保存并重复运行处理流程；生成新的派生版本；能查看进度、日志和失败原因；定时任务可暂停/恢复并留下运行记录。

## 任务拆分

| 子任务 | 状态 | 说明 |

| 2.4 构建与派生版本 | ⏳ 未开始 | 手动运行整条流程，生成不可变派生版本，记录进度、日志和失败原因 |
| 2.5 定时调度 | ⏳ 未开始 | 定时运行、暂停/恢复、运行记录、无变化跳过 |
| 2.6 来源追踪 | ⏳ 未开始 | 数据来源、经过的处理、下游影响 |

## 已确认约束

- 处理流程只读取数据连接同步生成的数据集，不直接访问外部数据库。
- 输出新的派生数据集版本，不覆盖原始数据集。
- 每次构建必须有运行记录，能区分成功、失败和无变化跳过。
- 数据集版本不可变；失败不改变当前版本。
- 所有功能沿用 Agent 对话 + 三栏工作台骨架，不另做一套菜单表单。
- 右侧操作通过结构化事件回流到中间对话，复用已有 `ConversationEvent` 机制。
- MVP 算子范围为筛选、选列、改名、改类型、合并（Union All）、关联（Inner/Left Join）；汇总等后置。
