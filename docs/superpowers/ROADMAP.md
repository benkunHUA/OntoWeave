## 3. 阶段依赖

```text
P1 数据进来
  └─ 产出：同步数据集 + 不可变版本
       └─ P2 数据整理
            └─ 产出：派生数据集 + 构建/调度/来源记录
                 └─ P3 变成对象
                      └─ 产出：对象实例 + 关系实例
                           └─ P4 Agent 使用
                                └─ 产出：动作执行 + 审计 + 闭环
```

每阶段只消费上一阶段的稳定产物：P2 只读同步生成的数据集，P3 只读已发布的数据集版本，P4 只操作已进入对象层的实例。

## 4. 阶段完成标准

| 阶段 | 完成标准 |
|---|---|
| P1 | 已保存连接能测试通过；选中的表能完成 snapshot 或 CDC 同步；成功同步生成不可变版本；失败不改变当前版本；对话能看到完整操作事件链。 |
| P2 | 能保存并重复运行处理流程；运行生成新的派生版本；能查看进度、日志和失败原因；定时任务可暂停/恢复并留下运行记录；输出数据集能查看直接来源版本和构建。 |
| P3 | 字段能映射到对象属性；指定唯一标识和显示名称；能生成并查询对象实例与关系实例。 |
| P4 | Agent 能查询对象、选择动作、填写参数、请求人工确认、执行并回读结果；每次执行留下谁、何时、改了什么。 |
