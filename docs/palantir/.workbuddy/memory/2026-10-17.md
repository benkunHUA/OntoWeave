## datapipline.json 文档摘要整理（Data connectivity & integration）

- 输入：`datapipline.json`（1181 个链接，1180 篇唯一文档；重复项 `api-reference/transforms-python-library/` ×2）。
- 产出：新建目录 `docs-summary-data-integration/`，含 34 个分类 md + README.md + index.json（格式对齐既有 `docs-summary/`）。
- 分类体系：按 URL 路径第 3 段（如 `pb-functions-expression`、`available-connectors`）分 34 类，按产品逻辑排序（总览→连接→Pipeline Builder→构建/优化/维护→代码仓库→各语言 Transforms→时间序列/地理空间→Iceberg/SQL 数仓→SAP/HyperAuto→媒体集→血缘等）。
- 流程：全部 1181 页 curl 实际抓取（3 进程×16 并行，约 8 分钟）→ parse_docs_html.py 解析 → 43 批 general-purpose 子代理并行写中文摘要 → 合并校验（覆盖率/枚举/中文非空/URL 集合一致性全部通过）。
- 类型分布：参考手册 677、操作指南 196、概念介绍 101、配置指南 78、概述 66、最佳实践 19、故障排查 16、工具说明 15、快速入门 11、发布公告 1。
- 特例：`announcements/release-notes/?filters=data-integration` 为 JS 渲染列表页，摘要按页面性质撰写（doc_type=发布公告）。
- 技能修复：`docs-link-summarizer/scripts/parse_docs_html.py` 的 `clean_text` 中 `</\1>` 反向引用不存在的分组导致 Python 报错，已改为 void 标签 + 成对媒体标签两段式正则。
