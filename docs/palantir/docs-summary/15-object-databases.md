## 文档列表

### 1. Object databases • Object Storage v1 (Phonograph) [Planned deprecation]

- **文档类型**：参考手册
- **文档链接**：<https://www.palantir.com/docs/foundry/object-databases/object-storage-v1/>
- **文档摘要**：本页介绍 Object Storage v1 (Phonograph)——Ontology 的遗留后端存储，目前处于计划弃用阶段，将于 2026 年 6 月 30 日后不可用，需迁移至 OSv2。页面概述其用途（datasource 经注册后索引进 Phonograph 供查询）、注册（Registration）过程、索引状态（index status）以及增量与批量重建（reindexing）机制，供仍在使用 OSv1 的用户参考。
