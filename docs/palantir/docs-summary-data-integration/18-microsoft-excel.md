## 文档列表

### 1. Microsoft Excel • Transforms Excel Parser

- **文档类型**：工具说明
- **文档链接**：<https://www.palantir.com/docs/foundry/microsoft-excel/transforms-excel-parser/>
- **文档摘要**：本页说明 Palantir 提供的 transforms-excel-parser 库（工具说明）。该库封装 Apache POI，用于在 transforms-java 仓库中以最少配置从非结构化数据集内的 Microsoft Excel 文件抽取表格数据，支持推断不一致 schema、多 sheet 一次读取多输出、表单式字段抽取，以及 fail-fast/fail-safe 行为与增量处理。文中含安装依赖与多个用法示例。
