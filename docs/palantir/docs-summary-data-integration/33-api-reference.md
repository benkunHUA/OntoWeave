## 文档列表

### 1. transforms-python • transforms.api • Overview

- **文档类型**：参考手册
- **文档链接**：<https://www.palantir.com/docs/foundry/api-reference/transforms-python-library/>
- **文档摘要**：transforms-python 库的 API 参考索引页，介绍 transforms.api 提供的用于构建 Pipeline 的类与装饰器。页面列出 configure、incremental、lightweight、transform、transform_df 等函数，并给出读取/写入数据集的最小示例。通过 Input、Output、LightweightInput 等接口支持 Polars、pandas、DuckDB、PySpark 多计算引擎，供开发者按需查阅各函数参数与用法。
