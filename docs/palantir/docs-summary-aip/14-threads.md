## 文档列表

### 1. AIP Threads • Overview

- **文档类型**：概述
- **文档链接**：<https://www.palantir.com/docs/foundry/threads/overview/>
- **文档摘要**：AIP Threads 是面向企业的生产力工具，用 LLM 完成各类任务与临时分析，需启用 AIP 与 AIP custom workflows。可拖拽上传 PDF 等文档或选择 AIP Chatbot（原 AIP Agents），适合技术手册问答、合同摘要、政策与法规解读、HR 政策检索等场景。

### 2. AIP Threads • Getting started

- **文档类型**：快速入门
- **文档链接**：<https://www.palantir.com/docs/foundry/threads/getting-started/>
- **文档摘要**：教程以「上传文档、与文档对话、与 AIP Chatbot 对话」为主线介绍入门操作：左侧为 thread 导航（新建、删除、深色模式、导出 JSON/PDF），右侧用 Document card 上传原生 PDF，在 Thread configuration 中选择 Chatbot 或模型模式后开始对话。
